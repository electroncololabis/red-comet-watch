赤色彗星补给战情室 1.2.0

适用：Windows 11，Intel 或 AMD 的 64 位电脑。
安装器允许在 Windows 10 上安装，但兼容性尚未验证；此包不适用于 Mac。
搜索组件当前官方支持范围：https://playwright.dev/python/docs/intro#system-requirements
已包含运行环境，不需要安装 Python、Codex 或开发工具。
搜索需要联网，电脑需已安装 Microsoft Edge 或 Google Chrome。

一、安装和第一次使用
1. 双击 RedCometWatch-1.2.0-Windows-x64-Setup.exe，按提示完成普通用户安装。首次安装请选择默认位置或空目录，升级请选择原安装目录。
2. 在 Windows 开始菜单打开“赤色彗星补给战情室”。安装时也可勾选创建桌面快捷方式。安装结束后的启动选项默认关闭。
3. 点“闲鱼登录”和“拼多多登录”，在这台电脑上分别完成登录。
4. 新增所需关注型号，选择平台后点“搜索全部关注”。
5. 如需自动搜索，在“自动任务”中主动部署。新电脑需要重新部署一次。
6. 可在“外观皮肤”中选用不同配色。

二、使用习惯
关闭网页不会退出后台，再次双击桌面入口即可重新打开。
完全退出：Windows 开始菜单 → 赤色彗星补给战情室 → 退出战情室后台。
程序正在搜索时，请等待完成后退出或卸载。
每次搜索会更新汇率并换算全部已填写日元发售价的型号。
未核实型号的发售价可在“编辑”里补充。
商品的“删除并屏蔽”在本机永久保存，可在“已屏蔽”中恢复。

三、把原电脑的数据带过来（可选）
安装包为新用户提供通用配置，收货省市留空，不包含原电脑的平台登录信息、历史报价和购买记录。
可备份自己的 hguc_watch.db 以迁移关注、历史、屏蔽、采购记录和应用内设置。备份前从开始菜单退出旧电脑的程序后台。备份包含个人记录，请妥善保管。
1. 在新电脑先打开程序一次，再从开始菜单“退出战情室后台”。
2. 从开始菜单点“打开数据文件夹”。
3. 将该目录原有的 hguc_watch.db 另存一份备份。若同目录还有 hguc_watch.db-wal 或 hguc_watch.db-shm，一并移到备份目录。
4. 将从旧电脑备份的 hguc_watch.db 复制进此目录，替换原文件。
5. 再双击桌面入口。闲鱼、拼多多需要在新电脑重新登录。
数据目录：%LOCALAPPDATA%\RedCometWatch\data
两台电脑各自保存数据，不会自动同步。

四、升级、卸载和常见情况
程序按 Windows 当前用户安装，使用随附的私有 Python。安装器的系统登记限当前用户的卸载条目和所选快捷方式。Windows 默认浏览器、代理、防火墙、环境变量、开机启动和计划任务都不在安装步骤内。
升级时保留原安装位置；数据保存在独立目录，不会被安装包覆盖。
从“设置 → 应用 → 已安装的应用”或开始菜单的“卸载”入口卸载。卸载会移除程序、安装时创建的快捷方式和本安装版注册的自动任务。
当卸载询问是否清理数据时，选“否”可保留数据和登录状态，方便以后重新安装；选“是”会清理默认数据目录里的关注、历史、采购、屏蔽、设置、应用日志和两个平台的专用登录配置。删除无法撤销。请先关闭战情室打开的平台登录窗口。
静默卸载默认保留数据；管理员部署脚本可在卸载命令中明确添加 /PURGEDATA 以清理默认数据。通过环境变量设置了自定义数据目录时，请在卸载后按需手动清理该目录里的战情室数据。
如果提示端口被占用，请先退出旧版战情室；本地网页默认地址为 http://127.0.0.1:8765。
后台启动失败时可查看数据目录里的 desktop.log。
此安装包未进行代码签名，Windows 可能显示“未知发布者”。在 PowerShell 运行 Get-FileHash -Algorithm SHA256 .\RedCometWatch-1.2.0-Windows-x64-Setup.exe，通过单独渠道向提供方核对输出的散列值。
闲鱼和拼多多的自动化浏览器启用了 Chromium 沙箱；两个平台各自在战情室专用的浏览器配置里保存登录状态。
平台要求登录、验证码或提示系统繁忙时，按网页提示处理。
自动搜索需要电脑开机联网且 Windows 用户已登录。

验证范围：本机隔离安装目录、中文/空格路径、独立数据目录及打包后的浏览器驱动已验证。
尚未在另一台实体电脑上实测；如出现安装或运行错误，请记录提示内容。
